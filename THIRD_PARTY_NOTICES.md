## LMFDB-derived data

The package's `lmfdb_baseline.csv`, and therefore `data/targets/baseline_signatures.csv`, is
"generated from the LMFDB degree-24 data" (LMFDB baseline snapshot 2026-05-20, per the package's
`competition/baseline/README.md`). The package states no LMFDB-specific terms beyond its Apache-2.0
license.

At run time, `src/igp/lmfdb.py` queries the LMFDB's public read-only database mirror for base number
fields. Some scripts and notes also contain individual defining polynomials of LMFDB number fields,
used as construction inputs. If you use this material, please cite the LMFDB:
The LMFDB Collaboration, *The L-functions and modular forms database*, <https://www.lmfdb.org>.

## Polynomials and families from the literature

`scripts/search_ctl.py` contains a few polynomials and one family taken from published work. They
are cited in the code comments:

- D. P. Roberts, "Lightly ramified number fields with Galois group S.M12.A", arXiv:1404.0429:
  an `M12.2` (`24T18441`) polynomial.
- J. Bosman, arXiv:0710.1237: a `PGL(2,23)` (`24T10255`) polynomial from level-1 modular forms.
- arXiv:1204.1328: the `M24` family over `Q(t)` used by `produce_m24`.
- One degree-24 LMFDB field polynomial (`24T201`).
