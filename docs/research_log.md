## State of belief

**Phase 0 (scope & survey), opened 2026-06-24 — no tests run yet.** Working picture from the
announcement + a first orientation search:

- The task is **constructive realization**: exhibit irreducible degree-24 integer polynomials with
  Galois group `24Tt` for as many of the 25,000 transitive groups (and their `(t,r)` signatures) as
  possible, ranked per signature by **smallest discriminant**.
- **Baseline to beat: LMFDB covers 286 groups / 622 of the 165,836 signatures** — so coverage is
  wide open. By Shafarevich every *solvable* group is realizable over `Q`; the open game is
  *explicit* realizations with *small* discriminant, plus the non-solvable / primitive groups.
- The likely structure of the work: **(a) mine databases** (LMFDB, Klüners–Malle, Jones–Roberts,
  Awtrey) for free coverage; **(b) extend cheaply** via subfields / resolvents / block-system
  (imprimitive) constructions since `24 = 2³·3` admits many block sizes; **(c) targeted
  low-discriminant searches** and **specialization of realizing families** for score and for the
  hard groups. Verification is via **MAGMA (SAIR API) / PARI-GP**, a budgeted resource → cheap local
  pre-filters (Frobenius cycle types mod good primes, resolvent factorization) before API calls.
- Unverified spec items (overview page 403'd unauthenticated) are flagged in
  `docs/competition_rules.md` — exact submission schema, scoring formula, API limits.

First targets: stand up the verification loop + reproduce the 286/622 baseline (test 0001), and run
the deep-dive landscape survey (Track 1).

### Update (2026-06-24) — M2 compositum method VALIDATED (first scoreable pairs); pivot to Phase 1

`scripts/q04` built 4 imprimitive degree-24 fields as composita of smaller fields and submitted them.
Magma labels + scoring: **24T679 (r=4), 24T12205 (r=4), 24T19234 (r=2) — all non-baseline, `scoreable=True`
(exact_nfdisc)**; 24T30 (r=8, the small C_2^3×S_3) was baseline. So **compositum/product-action (G1) is a
validated generator of non-baseline scoreable pairs**, and large/odd imprimitive groups are reliably
non-baseline while small-order ones tend to be baseline. 3/5 scoreable pairs toward the 100/day unlock.
This ends the one-off phase → **Phase 1: systematic coverage campaign** (`docs/phase_1_plan.md`): build an
autonomous generate→batch-submit→record engine across approaches G1–G6, measured, breadth-first.

`scripts/q05` G1 sweep (palette of small fields × degree partitions): **18 distinct 24Tt in one batch**.
Pattern confirmed: **small constituent groups → baseline** (24T2/3/38/71/254/27/250), **large (S6,S8) →
non-baseline** (24T5329/5331/7790/9739/9/17919). Scoring is async + slow for big-disc composita (3
finalized scoreable, 14 pending nfdisc). Realized DB: `data/targets/realized.csv`.
**Lean research find (G2):** polynomial *composition* `f(g(x))` realizes the **wreath product**
Gal(g)≀Gal(f) (full imprimitive group, b blocks of size a) — distinct from *compositum* which gives the
**direct-product action** (G1). Composition is cheaper (just substitute) and reaches larger groups →
strong non-baseline generator. Source: arXiv 2306.14386. Use in the next batch.

### Update (2026-06-24) — landscape survey round 1 done (`docs/landscape_survey.md`)

Deep-research round 1 (5 angles, 25 sources, 22/25 claims confirmed 3-0) locked the factual substrate
and named the construction methods, **without** yet verifying the per-method recipes (round-2 target).
Belief now:

- **Imprimitive/wreath constructions (M2) are the workhorse** — **5 primitive of 25,000**, so ~99.98%
  are imprimitive, and Hulpke's classification *builds* them from smaller divisor-degree fields
  (degrees | 24 = 2,3,4,6,8,12); the tower→wreath embedding makes the number-theory mirror exact.
  Stage-1 breadth is won here.

  small explicit polynomials need real construction (M4 CFT / M8 generic / M2 towers).

  `Q(t)`-families to specialize (M3) — e.g. **Müller's `M_24`** family.
- **Verification is not the bottleneck:** Magma's degree-independent `GaloisGroup` (Fieker–Klüners) IDs
  degree-24 groups "in seconds"; PARI `galoisinit` only does weakly-supersolvable, but `nfdisc` gives
  the **scoring** discriminant (field disc, 60 s/poly, mixed-disc fallback). Frobenius-cycle-type
  factoring mod p is the cheap pre-filter. The real work is *construction + discriminant minimization*,
  not identification. Arsenal: `docs/design/arsenal.md`.
