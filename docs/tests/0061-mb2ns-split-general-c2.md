## Method

For each target's base top: pull totally-real LMFDB deg-12 bases (`max_r2=0`), find completely-
split primes (`gp.split_primes`, k=2), sweep the gen12 diverse C_2-kernel w-patterns
(`_gen12_pats`, popcount 1..4), build `gp.general_c2(base, w, q)` → deg-24 coeffs. Local gate:
(1) deg-24 irreducible, (2) `polsturm` r in the matched group's open needed-r set, (3) Frobenius
cycle-type density over ~540 primes matches ONE of the 7 targets with **L1 < 0.35 and 0 impossible
cycle types** (GAP Chebotarev distributions in `data/processed/mb2ns/gdist.json`, generated by
`scripts/mb2ns_gdist.g`), (4) `gp.scoreable_disc` non-blank.

The density gate cleanly separates target from collapse: a correct 24T9633 build shows L1≈0.17–0.20,
imp=0; an overgroup/wreath build shows L1≈1.0, imp=12–33. Verified directly on the 12T183 r=16
build: L1(20699)=0.198 imp=0 vs L1(16607)=0.668 imp=7 vs L1(14616)=0.605 imp=10 — genuinely the
full overgroup 20699, not the intended subgroup.

## Learnings

- The `dim soc(K)=1` module-reachability proof (dive #30) is necessary but NOT sufficient for a
  **blind** landing: reachability says a √alpha exists in the right square-class; the blind sweep
  picks the *generic* class, which for 6 of 7 lands the full wreath / overgroup. Only 24T9633 (base
  12T33) has its target class coincide with the generic one.
- The GAP-Chebotarev density gate discriminates nested overgroups reliably at ~540 primes
  (subgroup vs full wreath: imp jumps 0→7–33, L1 0.2→0.6–1.0), so it is a budget-safe pre-Magma
  filter here.
- 12T230 totally-real bases have no completely-split prime under 20000 — raising the bound is the
  cheap first thing to try if 19246 is revisited.
