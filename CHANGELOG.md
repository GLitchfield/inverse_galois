## 2026-06-24 — Project scaffolded (Phase 0 opened)

Initial scaffold for the SAIR Inverse Galois Problem competition (IGP24). Mirrors the
conventions of the sibling `modular_arithmetic_challenge` project (docs layout, numbered
tests in `docs/tests/`, `research_log.md` + `commentary.md`, `trash/`/`archive/` discipline,
phase plans, README↔CLAUDE sync) but with a **computational-number-theory** stack
(PARI/GP, GAP, LMFDB, SAIR MAGMA API) rather than the ML/torch/wandb stack — IGP24 is a
search-and-verify problem, not a model-training one. Phase 0 (scope & survey) opened;
deep-dive landscape research pending.
